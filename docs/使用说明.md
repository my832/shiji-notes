# 拾记 1.3.1

安装包：`shiji-1.3.1.apk`。支持 Android 8.0 及以上。直接覆盖安装旧版可保留便签。修正顶部状态栏与弹窗遮罩的衔接，支持主题图标切换、顶部安全间距和键盘避让。保留液态玻璃效果。

新版将流动和常驻改成两个分页，卡片占满宽度。重要程度只保留普通、重要、紧急。点击完成后便签立即从分页消失，保存于归档盒，可以撤销或恢复。回收站支持单条恢复、恢复全部，以及确认后删除全部；分页满时，无法恢复的项目继续留在回收站。

## 两栏便签

- **流动便签**：最多 10 张。
- **常驻便签**：最多 5 张。指应用内固定保留的栏位。
- 按住便签右上角的六个点，上下拖动排序。点 `⋯` 可一键置顶，也可上移、下移或移到另一栏。
- 满栏时不能继续添加、移入或恢复。归档、删除可以释放栏位。
- 初次打开有 3 张使用指南便签，可直接编辑或删除。

## 颜色与内容

| 颜色 | 状态 |
| --- | --- |
| 蓝色 | 普通待办 |
| 橘色 | 重要待办 |
| 红色 | 紧急事项 |
| 绿色 | 已完成 |

点击卡片正文编辑。可输入标题、多行文字、标签和截止日期，添加图片或其他文件。图片可点击放大；其他附件使用手机上支持该格式的应用打开。

单个附件最多 **20 MB**，每张便签最多 **8 个附件**。附件复制到应用的本地存储，原文件移走后仍可使用。

点“完成”后便签收入归档盒，恢复时使用原来的重要程度。截止日期会显示“今天截止”或“已逾期”；当前版本不发送系统闹钟通知。

## 更多功能

- 搜索标题、正文、标签和附件名称；点击标签也能搜索。
- 筛选普通、重要、紧急、完成、所有待办和逾期事项。
- 亮色、暗色、跟随安卓系统三种外观设置。
- 未保存的文字和附件保留为草稿，再打开同一张便签可恢复修改。
- 归档盒、批量归档已完成、回收站，以及删除后短时间内撤销。
- 永久删除需要确认；归档及回收站的便签不占两栏的活动名额。
- 通过安卓分享菜单分享便签文字。

## 备份与恢复

右上角菜单 → **导出完整备份**，选择保存位置，生成 `.shiji` 文件。备份包含活动便签、归档、回收站、草稿、图片、文件附件和主题设置。

菜单 → **从备份恢复**，选择本应用导出的 `.shiji` 文件。应用先检查格式和附件，再显示恢复确认。恢复会替换现有便签、附件和设置，建议先导出当前备份。导入文件解压后最多 500 MB；较大的资料可分开保存。

数据保存于手机本地，无需账号，APK 未申请联网权限。卸载应用或清除应用数据会移除本地内容，请提前导出备份。常驻栏暂不包含桌面小组件、悬浮窗或通知栏便签。
